# Latvian TTS Model

## Training Data Preparation

Scripts and resources for preparing Latvian-language training data for fine-tuning the `moss_tts_local` model.

### Data Preparation

* `./data/yt_audio_processing.py` — processes YouTube audio and subtitles for dataset preparation.

### Current Data Sources

* YouTube videos with available subtitles.
